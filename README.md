
## Introduction

The Murata [Type2KU Module](https://www.murata.com/products/connectivitymodule/wi-fi-bluetooth/overview/lineup/type2ku) is a Wi-Fi/BLE combo module (supporting Wi-Fi 6) based on Beken’s BK7236 IC. This SDK, built upon the original BK7236 IDK with additional Murata Type2KU patches, aims to provide an easy-to-use development environment for customers. The SDK folder structure is as follows:

```
├── bk_idk
├── build
│   └── app
├── components
│   ├── CMakeLists.txt
│   ├── tools
│       └──Makefile
│   └── murata
│       ├── CMakeLists.txt
│       ├── Kconfig
│       ├── lib2ku.a
├── Makefile -> components/tools/Makefile
├── module
│   └── bk7236
│       └── type2ku.defconfig
│       └── otp2.csv
├── idk_patches
├── projects
│   └── app
```

- bk_idk: the original IDK from Beken
- build : Automatically generated by the build system; the compiled binary firmware will be placed here.
- components : Libraries provided by Murata for the Type2KU module.
- Makefile : Makefiles for compiling the project.
- module : Module configurations provided by Murata for the IDK.
- idk_patches: Patches from Murata for the Type2KU module, which need to be applied to the IDK.
- projects : Folder for customer applications; IDK sample applications can also be copied here for compilation.

## Apply the IDK patches

After fetching the entire SDK, please apply the necessary patches to the IDK using the following shell command:

```
./idk_install_patches.sh
```

## Build the default appliction

Once the patches have been applied, use the following command to compile the default application:

```
make bk7236 MODULE=type2ku PROJECT=app
```

<MODULE>: Specifies the target module configuration. Use `type2ku` for the Murata Type2KU module.
<PROJECT>: The name of the application folder within the `projects` directory.
